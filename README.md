# Quantum Escape

**Quantum Escape** est un jeu d'action développé en C utilisant la bibliothèque **SDL**.

## Description
Dans ce jeu, le joueur doit naviguer à travers différents niveaux, éviter des obstacles et résoudre des défis pour s'échapper. Le jeu intègre des interfaces utilisateur intuitives et des effets sonores pour une expérience immersive.

## Fonctionnalités
- Création et gestion de niveaux variés
- Conception d'interfaces utilisateur graphiques
- Ajout d'effets sonores pour améliorer l'immersion
- Gestion de la physique des personnages
- Optimisation des performances du jeu pour une expérience fluide

## Technologies utilisées
- Langage : C
- Bibliothèque : SDL (Simple DirectMedia Layer)
